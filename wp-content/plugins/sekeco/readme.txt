Content models, component blocks, forms and motion for the Sekeco block theme.

== Description ==

* Content types: Works (`portfolio`), Portfolio (`product`) and Team (`team`), sharing core categories.
* Component blocks, grouped in the inserter as Sekeco: Layout, Content and Utility: Section, Section header, Hero, Call to action, Marquee, Statement, Capabilities, Process, FAQ, Stats, Project grid, Form and Theme toggle.
* `sekeco/meta` block binding for custom fields.
* Form builder with REST submit, honeypot, time window and rate limit.
* GSAP motion runtime with a reduced-motion fallback, and a Motion panel for core Group and Cover blocks.
* Solar Line Duotone icons (CC BY 4.0).
